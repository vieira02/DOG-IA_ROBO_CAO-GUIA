Sobre o Projeto:

O DOG-IA - Robô Cão-Guia Urbano de Inteligência Assistiva é um projeto voltado ao desenvolvimento de um protótipo de robô-guia autônomo em ambiente simulado, com foco na mobilidade urbana para pessoas com deficiência visual.

O projeto envolve conceitos de robótica, navegação autônoma, sensores, visão computacional e interação humano-robô.
